I am a software engineer in Irvine, California, working on data platforms, backend services and LLM agents for business workflows.

Over fifteen years I have built the systems behind data-heavy businesses: the event-driven algorithm module, portfolio dashboard and market-data warehouse of a hedge fund's trading platform; PB-scale feature pipelines and GBDT ranking models for ads at Reddit; and signal-processing software for GPS and cellular chips at Broadcom. These days I build with coding agents: spec-driven development with Claude Code, tool-using agents on the Anthropic API, MCP servers, and evals that run in CI. I like working directly with the people who use what I build.

Selected Project

ask-edgar is a text-to-SQL LLM agent with evals over SEC financial statement data. The SEC Financial Statement Data Sets (3.7M facts in four denormalised tables, 44 XBRL tags mapped to 31 metrics) are modelled into a dbt warehouse on Postgres. A tool-using agent on the Anthropic Messages API writes the SQL behind a code-level guard (sqlglot parsing, schema allow-list, READ ONLY transactions with statement timeouts). An eval set with ground truth computed by oracle SQL and record/replay cassettes runs in GitHub Actions without an API key. CLI, FastAPI and MCP server interfaces.
